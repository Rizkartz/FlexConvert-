# FlexConvert

FlexConvert is a versatile file converter API and backend. It supports conversions for images, documents, spreadsheets, audio, video, archives, and data files.

## Setup Instructions (English)
1. **Install dependencies:** `pip install -r requirements.txt`
2. **Install FFmpeg:** Required for audio and video conversions. Make sure `ffmpeg` is available in your system's PATH.
3. **Run the server:** `python run.py`
4. **Access the API:** The server runs at `http://localhost:8000`. You can view the API documentation at `http://localhost:8000/docs`.
